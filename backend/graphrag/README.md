# 图检索

构建时合并主图谱与 `knowledge/corpus/guidelines/*.json` 内的独立指南。导出的快照包含合并后的概念和证据，可单独加载。指南中的文本摘要也供关闭图谱时的基础检索使用。

基础条款由 `knowledge/corpus.py` 独立加载。概念、关系和锚点可选，未关联概念的条款通过文本通道召回；图谱只沿已定义的方向关系和概念锚点查找证据。图谱加载失败时保留基础条款。

设置 `RAG_ENABLED=1` 和 `GRAPH_RAG_ENABLED=1` 后，报告和眼科问答可使用图检索与基础检索融合。配置 `RAG_MODE=bm25` 可在本地跳过向量模型下载。

图谱命中会参与 RRF 排名。文本通道召回的条款即使已有锚点、本轮只命中文本，也可参与融合。各通道共用条款的语言与出处。指南的图谱字段格式错误时，该次索引使用基础检索。

`builder.py` 加载并校验眼科图谱，`retriever.py` 根据概念和关系召回带出处的证据。内置数据包含概念、方向关系、来源和条款。命中证据可以包含 `graph_path`。图谱加载失败时使用基础检索。 [图谱数据](../knowledge/corpus/ophthalmology-graph.json) · [配置与示例](../README.md#graphrag)
