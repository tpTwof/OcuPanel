# 后端回归测试

`test_screening_imports.py` 覆盖服务端导入预览与确认、双眼分开、旧原图缺失、研究分数及校验状态保留、所有者隔离、幂等和预览重放、来源或病例冲突、过期、文件篡改、声明边界、元数据修订、事务回滚及上下文/JSON/PDF 一致性。`test_routes.py` 另验证采集字段的 multipart 兼容及带时区时间。全部使用临时存储，不运行真实推理或 LLM。可用 `tools/serve_screening_acceptance.py` 启动隔离浏览器验收环境，步骤见[二次验收](../../docs/病例工作台导入实现与二次验收.md)。

`test_screening.py` 覆盖双眼不同结果、补拍、复核和模拟签发、转诊回执、历史释义与 PDF 一致性、重试及并发幂等、旧版本冲突、账号隔离和拒绝真实病例标记。`test_screening_evaluation.py` 覆盖患者跨集泄漏、未知结局、弃判、配对患者 bootstrap 与零分母。所有病例均为合成记录，不访问模型或网络。

`test_vision_baseline.py` 验证处理器与权重使用相同提交、版本参与缓存、文件哈希准确，以及拒绝浮动版本冻结。真实缓存样例的离线回放输出另存 [旧方法基线](../../docs/baselines/README.md)。

安装 [后端依赖](../../README.md#安装指南) 后，从仓库根目录运行。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s backend/tests
```

测试覆盖 API、会话模式与上下文、报告流程、Agent 工具、引用校验及视觉数值逻辑，使用模拟模型调用。真实模型与产出验证见 [影像分析](../modules/vision/README.md)，运行中实例的账号隔离自检见 [开发工具](../../tools/README.md)。

`test_verifier.py` 另覆盖校验失败分类及错误提示，确保模型请求或响应格式错误不被描述为缺少病例资料，且错误详情不泄露到报告。

格式回归覆盖 `claims` 无效后重试成功、持续无效时有界失败、复核格式出错和请求失败不重复调用，并确保格式恢复后仍拦截未知引用编号。

`test_verifier.py` 和 `test_report.py` 覆盖非核心说明删除后全文复核、核心/混合问题阻断、未知编号不允许降级、片段或重复位置禁止自动删除、删空/复核故障拒答、相同改写不计修复，以及病例事实和结构化测量值保留。病种模型与 LLM 输出在这些回归中固定，不代表真实病例或模型的临床验证。

`test_routes.py` 另检查局部清理后的聊天消息、存档和实际 PDF 导出使用同一份已复核正文，删除原句及原因只进入校验记录；既有拒答与账号隔离导出检查继续执行。

`test_grounding.py` 验证原始支持片段、每个引用位置的来源覆盖、病例推理的双来源、一般建议不能包装具体数量/周期、软件与资料边界、来源归类复核及未知引用。`test_verifier.py` 另验证病例原文匹配、混合句只改建议、禁止猜测位置或改动未点名事实、Markdown 引用定位、上下文/版本审计及重生成异常后仍保留问题。测试检查软件契约，语义与适用性需另用固定专科题库评估。

`test_report.py` / `test_routes.py` 另验证 `limited` 只交付原始病例、不混入未核实诊疗草稿，存档/会话保留拒答标记且两个 PDF 入口继续阻断。故障和无证据不转换为通过状态。

`test_report_retrieval.py` 覆盖病种词已在查询中时仍加权、向量主题位于长病例前，以及 Sample 青光眼记录召回诊断评估条款、不混入 DME 条款的离线 BM25 场景。图谱与向量缓存的其他回归由 `test_graphrag.py` 覆盖。

`test_grounding.py` 另验证 `statement_id` 指向跨分句加粗文字时，实际存在的原文片段仍能正确关联，不因片段自身没有完整 Markdown 标记而误报不匹配。

同文件还区分列表序号与处置数量，并验证地区/场景说明可核对原始范围元数据，医学知识不能借用同一元数据替代正文证据。

## 青光眼合成病例回放

以下命令逐例打印通过或失败，便于在更改测量、撰稿或校验后比较结果。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s backend/tests -p test_glaucoma_cases.py -v
```

| 固定场景 | 核对的报告行为 |
| --- | --- |
| 75 个视盘环像素、25 个视杯像素 | 面积等效杯盘比为 0.50，保留模拟条款及正文编号 |
| 只有视杯像素 | 杯盘比缺失，保留视盘环缺失提示 |
| 已测量但无检索证据 | 保留测量值，拒答且模型调用次数为零 |
| 引用核查返回无效结构 | 校验状态为 error，扣留草稿 |

图片和掩膜为程序合成，分类概率、检索命中和语言模型回复固定。回放经过实际的图像读取、测量、叠加图生成及报告校验流程，用来比较软件行为。真实病例上的模型表现仍需单独评估。

全路线回归新增合成机构与账号、报告任务、按版本调阅原图及叠加图、签发后随访、到期清理与损坏快照。测试在临时目录执行，使用受控推理结果覆盖任务中断前后的归档行为。评估 CLI 复用仓库中的四病种合成输入。[2026-11-25 验收记录](../../docs/升级验收.md)

`test_layout.py` 检查数据库、报告输出、原图及语料路径在模块迁移后仍定位到 backend；文本检索和图检索共用已有语料目录。
