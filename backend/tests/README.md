# 后端回归测试

安装 [后端依赖](../../README.md#安装指南) 后，从仓库根目录运行。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s backend/tests
```

测试覆盖 API、会话模式与上下文、报告流程、Agent 工具、引用校验及视觉数值逻辑，使用模拟模型调用。真实模型与产出验证见 [影像分析](../vision/README.md)，运行中实例的账号隔离自检见 [开发工具](../../tools/README.md)。

## 青光眼合成病例回放

以下命令逐例打印通过或失败，便于在更改测量、撰稿或校验后比较结果。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s backend/tests -p test_glaucoma_cases.py -v
```

| 固定场景 | 核对的报告行为 |
| --- | --- |
| 75 个视盘环像素、25 个视杯像素 | 面积等效杯盘比为 0.50，保留模拟条款及正文编号 |
| 只有视杯像素 | 杯盘比缺失，保留视盘环缺失提示 |
| 已测量但无检索证据 | 保留测量值，拒答且模型调用次数为零 |
| 引用核查返回无效结构 | 校验状态为 error，扣留草稿 |

图片和掩膜为程序合成，分类概率、检索命中和语言模型回复固定。回放经过实际的图像读取、测量、叠加图生成及报告校验流程，用来比较软件行为。真实病例上的模型表现仍需单独评估。
