# 2026-10-26 · OcuPanel 与账户体系

## 更改了哪些

- 从 MedChat 演进为 OcuPanel，增加用户账户、SQLite 持久化和个人 LLM 配置。
- 加入青光眼本地语料、按专科召回及报告引用校验。
- 将聊天的眼科助手提示与影像报告链路分开。
- 整理安装与模块说明，统一项目和数据库名称。

## 业务板块

| 板块 | 内容 |
| --- | --- |
| 账户与设置 | 账户登录后在个人设置保存模型配置。用户、会话与报告由 SQLite 持久化。 |
| 聊天 | 建立或打开会话，眼科问答使用独立提示词。 |
| 视觉与报告 | 继续使用青光眼分类和分割。增加诊断、随访和治疗相关本地证据，按专科召回后用于综合报告及引用校验。 |

## 业务流程

登录与配置模型 → 建立或打开会话 → 提交眼底图与备注 → 青光眼视觉分析 → 各专科检索与撰稿 → 汇总与校验 → 查看报告及追问。
