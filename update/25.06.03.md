# 2025-06-03 · 初始 MedChat

## 更改了哪些

- 建立前端与 Python 后端，接通眼底照片、临床记录与青光眼报告。
- 使用青光眼分类、视盘视杯分割和杯盘比作为病例输入。
- 按角色生成意见，通过 Director 综合报告。

## 业务板块

| 板块 | 内容 |
| --- | --- |
| 影像分析 | 聚焦青光眼。分类模型给出预测，分割结果用于生成视盘视杯图和杯盘比。 |
| 报告 | 专科角色覆盖眼科医生、验光师、青光眼专科医生、全科医生、眼科技师、药师。生成器复用角色提示模板，Director 综合结果。 |
| 问答与导出 | 浏览器上传后查看报告，可追问并生成 PDF。 |

## 业务流程

眼底照片与临床记录 → 青光眼分类与分割 → 病例提示 → 专科子报告 → Director → 展示、追问或 PDF。
