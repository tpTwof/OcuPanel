# 2026-11-18 · 11 月 19 日修改前的工作区基线

## 更改了哪些

- 眼科分析支持单选或多选青光眼、糖尿病视网膜病变（DR）和年龄相关性黄斑变性（AMD）。
- 青光眼从六个职业角色收敛为一个病种专科。DR 和 AMD 分别撰写病种分析。
- 接入可选 GraphRAG、DR 和 AMD 本地证据，以及已保存报告的 PDF 导出。
- 根目录项目说明将 OcuPanel 定位为多病种辅助分析项目。

## 业务板块

| 板块 | 修改前状态 |
| --- | --- |
| 视觉 | Python 按用户选择执行检查。青光眼返回分类输出、面积等效杯盘比和分割图。DR、AMD 复用 FLAIR 图像编码并分别返回研究性匹配差值。 |
| 检索 | 用所有病种的病例上下文检索一次。各专科共用一个证据包。 |
| 撰稿 | 各病种专科撰写子报告，Director 在单病种和多病种时都运行。 |
| 校验与交付 | Verifier 处理正文引用。FLAIR 分数在正文校验后拼进摘要。页面可展示证据，已保存的报告可重新导出 PDF。 |

## 业务流程

选择病种 → 视觉批处理 → 全病例检索并编号 → 专科撰稿 → Director → Verifier → 拼入 FLAIR 分数 → 保存、展示或拒答。
