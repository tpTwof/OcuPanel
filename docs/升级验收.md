## 用一例双眼结果不同的病例走读

1. 登录，进入工作台，新建合成病例并点击「填入双眼示例」。核对右眼可疑、左眼不可判读，左眼已保存两次采集和补查安排；跟进人不能为空。
2. 保存，记录合成原图与病例复核，再保存逐眼模拟签发计划。查看签发版本号。
3. 建立双眼转诊，填接收科室和跟进期限。只记录「已接单」时仍应出现在待跟进列表，再记录「已到诊」。
4. 选择签发时的历史版本，查看逐眼释义并导出 JSON 与演练 PDF。三者左眼必须保持不可判读，不能出现阴性推断。
5. 回到最新版，修订或补拍。当前复核与签发清空；旧签发快照和旧转诊引用保持原样。重新复核后才能模拟签发新版。
6. 通过 API 重放同一幂等键与内容，结果和版本数不变；修改内容但沿用幂等键应返回 409。并发更新旧版本也应返回 409。
7. 切换另一账号，病例、旧快照和导出均不可访问。退出登录后所有新接口返回 401。
8. 勾选立即人工交接标记或登记模型离线移交，确认无需等待模型或报告，跟进责任人始终保留。
