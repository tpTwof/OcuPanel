# OcuPanel 眼科业务升级路线图

**建议首个业务是成人眼底阅片与转诊协作。** 采集人员能在受检者离场前发现需要重拍的照片，眼科医生能在同一处看到原图、可疑所见和缺失检查，转诊负责人能知道谁尚未到诊。首期用这三件事衡量价值。青光眼沿用现有研究方法，出现有望改善漏转或复核负荷的候选时再验证，糖尿病视网膜病变（DR）随后验证转诊筛查，年龄相关性黄斑变性（AMD）优先建设可疑病例的专科转诊路径。

本文是 2026-11-24 的建设提案，依据工作区代码（基线提交 `41b861f`）。暂按**中国大陆医疗机构、成人、由眼科医生复核**设计。合作机构、采集设备、病例授权、临床负责人和可接受漏转水平仍待确定。当前发布能力及验证程度见[项目说明](../README.md)和[视觉模块验证记录](../backend/vision/README.md)。

## 二、把一次报告变成一次有去向的就诊

1. **受理与采集。** 建立机构内就诊编号，关联左右眼、采集时间、设备、视野、症状起始和已有检查。先问急性危险症状。任一入口命中机构审核的急症规则，直接展示就医指引并交接，当次无需等待图片、检索或模型响应。
2. **质控与阅片。** 按任务给出质量原因和下一步。视盘清晰而黄斑曝光过度时，分别记录两区可见性。可补拍时当场补拍，持续不可判读或不适宜拍摄则进入人工检查。医生在原图上核对左右眼、所见位置及依据，能修改、驳回或追加检查，并记录原因。
3. **签发与交接。** 保存影像所见、引用校验、医生意见三份记录。向患者展示签发版的去向、紧急度、责任科室及下一步。转诊有接收人、发起时间、到诊回执和处理结局。逾期由指定人员联系并记录。人工修订另存版本，历史 PDF、追问与转诊单均指向当时签发的一版。
4. **治疗与随访。** 医生制定治疗与复查计划后，助手可释义已有医嘱、整理复诊问题、提醒约定的检查、登记依从情况及新症状。医生端如需比较治疗选项，列出适用人群、必要检查、禁忌及对应原文。患者要求停药、换药或调整注射间隔时，展示当前有效医嘱并转接诊医生。若在境内开展互联网诊疗，处方由接诊医师本人开具。[国家卫健委《互联网诊疗监管细则（试行）》](https://www.nhc.gov.cn/yzygj/c100068/202203/2072f0e8988249e59d942e1b2a933916.shtml)

**一例应当如何结束。** 一位糖尿病患者双眼受检，右眼图像可判读，左眼连续补拍仍无法看清黄斑。医生签发右眼所见，左眼记录不可判读和面诊安排。患者追问“我两眼都没问题吗”，助手复述左右眼各自的结果和待办。接收科室回填左眼检查结果后才关闭转诊。这个病例可同时验收采集、报告、追问和随访四个入口。

## 三、出现更好候选时如何评估青光眼方法

把候选模型的任务定义为**在规定采集条件下识别值得眼科复核的青光眼性视神经损伤征象**。现场操作需要回答“哪一眼、为什么复核、接下来做什么”。例如，局部盘沿变窄、疑似盘缘线状出血应能指回原图。房角状态、视野损害及疾病分期分别依赖相应检查。面积等效 CDR 由像素面积比开平方得到，不能代入指南中垂直 CDR 的判据。[中国眼底照相 AI 青光眼辅助筛查指南，临床指导原则](https://www.gzzoc.org.cn/node/13850) · [NICE NG81，1.2.1–1.2.4](https://www.nice.org.uk/guidance/ng81/chapter/recommendations#diagnosis) · [现有测量定义](../backend/vision/README.md)

| 步骤 | 交付物及取舍 |
| --- | --- |
| 冻结旧方法 | 固定分类、分割权重的提交和哈希、处理器、类别顺序、掩膜语义及样例输出，作为离线对照。两份模型卡均记载用 REFUGE 微调。同源样本可做回归，独立验证另取机构与患者来源清楚的病例。[分类模型卡](https://huggingface.co/pamixsun/swinv2_tiny_for_glaucoma_classification) · [分割模型卡](https://huggingface.co/pamixsun/segformer_for_optic_disc_cup_segmentation) |
| 建立替代方法 | 先验证一套独立的质控和监督分类方法。用获准使用的彩照编码器提取特征，用专科阅片标签训练转诊分类器。结合质控结果区分“可疑需复核、可判读且未见目标征象、不可判读”。另标注盘沿、盘缘出血等可见征象和位置，模型只展示经过该项标注及验证的解释。可独立保留测量通过验证的分割器，质控失败时隐藏该项数值。眼压、房角镜、标准视野及光学相干断层扫描（OCT）等专科结果逐项记录来源，供医生确认诊断。 |
| 用相同病例比较 | 首轮研究可由两名眼科医生独立盲评照片是否值得转诊，分歧交第三人裁决。正式评价按适用规范锁定阅片人数、资质和裁决程序。临床诊断另由完整检查形成，标注时分开保存。旧分类分数和候选分数各自在校准集确定工作点，在同一外部盲测集比较漏转、误转、不可判读和工作量。REFUGE 的临床诊断与 AIROGS 的转诊阅片标签适合回答不同问题。AIROGS 公布的训练数据许可含非商业限制，立项时另核用途。[REFUGE 参考标准](https://refuge.grand-challenge.org/Details/) · [AIROGS 标注和许可](https://airogs.grand-challenge.org/data-and-challenge/) |
| 切换与退出 | 在现有 `analyze_fundus` 病种入口接入候选。保留 `EyeAnalysis.diseases`、既有 multipart 字段及存档语义，新状态通过版本化字段扩展。核对页面默认勾选和省略 `diseases` 时的后端默认行为。按机构、设备先做影子运行，即候选结果只进评估库，实际诊疗照常。独立验证和现场试点均通过后，才切换授权范围内的默认方法。若发现严重漏转或设备漂移，停用受影响版本，切回人工阅片，按版本查找受影响病例并复核。[视觉接口](../backend/vision/models.py) · [报告入口](../backend/report/generation.py) · [前端选择](../frontend/src/components/ReportView.jsx) |

OcuPanel 可以独立决定标签、算法和放行标准。交付时保留所用上游代码的版权及许可声明，分别登记模型权重、数据、指南摘录和再分发条件。[仓库 LICENSE](../LICENSE)

## 四、其余眼病按检查能力建设

下表用于设计机构工作流。每行的目标输出都需要专项验证和临床审核。指南版本、地区和推荐条款随规则保存，由试点科室确定本地转诊路径和时限。

| 病种与当前验证程度 | 采集什么、如何判断 | 面向业务的输出与验证 |
| --- | --- | --- |
| **DR**。已有 FLAIR 研究分数 | 采集糖尿病史、眼别、视力和按协议取得的眼底照。单视野先做筛查。完整分级须有充分视野及分级标注，记录微血管瘤、出血或新生血管等可见所见。 | 初筛可疑由眼科确认。先用双人分级标签验证转诊筛查，再另验五级分级。美国 ADA 2026 第 12.9 条将中度及以上非增殖期、任何增殖期及任何 DME 列为及时转诊对象。国内试点对照当地筛查路径定规则。[我国 DR 指南，临床问题 2](https://www.gzzoc.org.cn/node/13780) · [国内分级诊疗方案，第三部分](https://www.dx.gov.cn/dxwjw/0300/201705/2f2b83a000824d1aa7a0548cb43dfdb1.shtml) · [ADA 2026，第 12 章](https://doi.org/10.2337/dc26-S012) |
| **糖尿病黄斑水肿（DME）**。尚无专项模型 | 记录黄斑区是否可见、视力和可疑渗出。由专科结合 OCT 评估水肿和中心受累情况。 | 可输出“需黄斑 OCT 评估”。缺检查时保留“水肿状态未评估”。以同眼、合理时间窗内的 OCT 专家判读作参考，分别评估漏转及误转。[NICE NG242，1.6.11](https://www.nice.org.uk/guidance/ng242/chapter/Recommendations) |
| **AMD**。已有 FLAIR 研究分数 | 逐眼记录新发视物变形、中心视力变化及黄斑区照片。由阅片医生确认玻璃膜疣、色素改变或出血等所见，疑活动性新生血管性 AMD 时做 OCT，按需造影。 | 优先交付疑活动病例的加急黄斑专科转诊。用专科检查及结论验证漏转，单列把活动病例误分为常规随访的数量。照片分期和活动性判定各自验证。[中国 AMD 指南（2023）](https://doi.org/10.3760/cma.j.cn112142-20221222-00649) · [NICE NG82，1.4.6–1.4.9](https://www.nice.org.uk/guidance/ng82/chapter/recommendations) |
| **白内障、干眼**。已有问答资料，首期做检查导航 | 渐进模糊、眩光及生活影响可引导视力、裂隙灯晶状体检查。干涩、异物感记录病史，转眼表与泪膜评估。混浊眼底照只记录影响可见性及补查需求。 | 由医生审核分流、检查和已有治疗计划的释义。白内障术后问答还需核对手术眼、日期和签发医嘱。用眼前节门诊病例核对误分流及不适当用药建议。[国家卫健委《成人白内障手术操作规范（2026年版）》](https://www.nhc.gov.cn/cms-search/xxgk/getManuscriptXxgk.htm?id=5ba49ac3bf3148d8baab72c7547cc1bb) · [NEI 干眼公众教育](https://www.nei.nih.gov/eye-health-information/eye-conditions-and-diseases/dry-eye) |
| **疑视网膜脱离、视网膜动脉阻塞、急性闭角发作**。拟做症状分诊 | 新发闪光伴大量飞蚊或幕帘样遮挡，突发无痛单眼视力丧失，或突发剧烈眼痛伴红眼、视物模糊或恶心，都应触发立即就医指引。 | 直接联系眼科急诊或急诊，疑动脉阻塞按当地流程衔接卒中评估。即使照片看似正常或服务离线，也保留紧急指引。用医生标注的急症、相似非急症、否定表达及追问病例验证漏分诊和误报。[NEI 视网膜脱离](https://www.nei.nih.gov/eye-health-information/eye-conditions-and-diseases/retinal-detachment) · [AHA 视网膜中央动脉阻塞科学声明](https://professional.heart.org/en/science-news/management-of-central-retinal-artery-occlusion) · [NEI 闭角型青光眼](https://www.nei.nih.gov/eye-health-information/eye-conditions-and-diseases/glaucoma/types-glaucoma) |

**增加一个病种的最小交付物**是一张由专科负责人维护的病种卡。写清目标人群、排除情形、所需检查、可观察征象、可输出结论、危险症状、证据条款、转交对象和参考标准，并标明“仅宣教 / 研究评估 / 已验证的机构与设备”。进入影像选择器前，还需给出该任务独立验证的版本和结果。先对现有问答主题逐条审核，覆盖面才能与客户端的能力声明相符。

## 五、医生如何信任并追溯一条建议

- **影像和文字各自留据。** 一项病例所见关联就诊号、眼别、原图区域或检查记录、采集时间、质量和模型版本。一条诊疗知识关联稳定条款 ID、章节、地区、人群、版本、复核人及日期。在报告中区分患者自述、模型测量和医生确认的发现。任一环节缺失就显示具体缺项。[已有证据格式](../backend/knowledge/README.md) · [现有影像结果组装](../backend/report/generation.py)
- **把引用校验和医生签发分开验收。** 公众教育可支持概念释义。具体治疗建议需与本地适用指南、获准说明书及本例条件对应。相互冲突、来源过期或仅部分病种有据时，保留已有所见，明确哪一项待复核。患者版只引用医生已签发的计划。更新知识时保留旧版快照，复跑受影响病例。
- **固定问答验收题。** 测试“另一只眼可以排除吗”“能自行停药吗”“昨天左眼报告与今天右眼报告矛盾吗”，以及报告缺失、检索无据、急症伴低分的情形。医生逐条评估事实一致、条款适用、正确转交和不必要拒答。高风险错误须回溯到输入、检索、撰稿、校验或显示环节后修复。

## 六、按证据决定何时进入业务

| 阶段与牵头人 | 可验收的交付物 | 进入下一阶段的条件 |
| --- | --- | --- |
| **试点定义** · 产品负责人、试点科主任 | 选定一个采集点和接收科室，用现行人工流程测出每例阅片时间、日复核容量及转诊回执率。书面确认任务终点、适用设备、数据授权和临床风险预算。 | 医生明确何时补拍、何时转诊、谁签发、谁追踪失访。统计负责人按预期阳性例数和置信区间精度估算样本量，事前约定容许的漏转率、复核负荷上限和工作点选取规则。 |
| **离线验证** · 算法负责人、独立阅片组 | 按患者划分开发、校准、盲测集，双眼和重复就诊同组。留出独立机构或设备，覆盖低质图、早期病变、高度近视与共病。交付逐例盲评、分歧裁决、候选与旧版配对结果及误差分析。 | 报告工作点的灵敏度、特异度和 95% 置信区间，双眼相关性按患者处理。按机构、设备分层。质控同时报不可判读图误放率和可判读图误拒率，单列重拍与弃判。分割另报视盘、视杯 Dice 及同定义 CDR 误差。样本不足的子组标为未验证。 |
| **前瞻性影子试点** · 临床负责人、运营 | 连续纳入符合条件的就诊，候选输出对接诊者隐藏。保留现场人工决定、最终去向、漏转复盘、排队时间和每例成本。按方案核验转诊病例及抽样的筛查阴性病例，失访单列。 | 逐病种核对预设性能下限、不可判读率和每日复核量。覆盖率以全部入组者为分母。漏转率以参考标准确认应转者为分母，分子为其中未被流程转出的病例。未知结局单列，估计人群漏转率时校正抽样核验。未达标的任务回开发集修订，再用新的独立样本确认。 |
| **限范围使用与持续监测** · 医疗、产品、运维负责人 | 完成适用监管手续后，先在签约机构和已验证设备启用医生签发版。按班次监测严重漏转、人工改判、复核等待和转诊到诊率，与试点前基线比较。 | 出现已确认的严重漏转、错误眼别、越权签发或关键指标越界，暂停相关功能，转人工并追查受影响报告。新设备、新模型或新规则按影响复验后恢复。 |

其中，**业务成本按每份医生签发报告核算**，计入推理、存储、重拍和人工复核。到诊率按观察窗口内已到诊人数除以应转诊人数，同时列出仍在等待和失访的人数。临床负责人复盘每例漏转，运营负责人核对接收能力和交接延误，机构据此决定能否持续提供这项服务。

### 真实病例进入前的工程与治理工作
