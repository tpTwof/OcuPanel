# OcuPanel 业务模块说明

> 2026-11-19 审阅快照。后续修复及验证结果见[当日 v2](../../update/26-11-19-v2.md)。

OcuPanel 是面向研究和演示的眼科问答与眼底分析原型。用户可以直接聊天，也可以提交眼底照生成报告，再围绕该报告追问。以下按用户任务拆分，依据为 2026-11-19 当前工作区的页面、服务和存储实现，包含尚未提交的改动。

## 用户可以走哪几条流程

| 入口 | 用户操作 | 结果 |
| --- | --- | --- |
| 普通聊天 | 登录、配置模型、选择会话并提问 | 使用近期会话消息生成文本回复，问答留在本会话。 |
| 眼科助手 | 切换会话模式，提出眼科问题或追问已有报告 | 带入眼科提示和可用的最近报告，按配置检索、核查本轮证据。发消息本身不会启动影像推理。 |
| 眼科分析 | 上传眼底照、选择病种，可附临床记录 | 对所选病种运行视觉模型，生成报告正文或拒答说明。关联会话时，分析请求和报告进入历史，可继续追问。 |
| 历史导出 | 在历史会话中选择一份可导出的报告 | 从当前账号保存的正文和证据渲染 PDF，无须再次提交原图或调用生成模型。 |

## 模块及职责

| 业务模块 | 主要动作与输出 | 实现入口 |
| --- | --- | --- |
| 账号与登录态 | 注册、登录和注销。登录令牌标识请求用户，账号是会话、配置和报告的归属单位。 | [账号接口](../../backend/user/api.py) · [认证](../../backend/utils/auth.py) |
| 个人配置与使用情况 | 管理账号自己的模型地址、模型名和 API Key，测试连通性、查看用量统计。密钥加密保存，读取配置时返回掩码。页面另提供 PDF 保存偏好。 | [账号服务](../../backend/user/service.py) · [设置页](../../frontend/src/components/SettingsView.jsx) |
| 会话管理 | 新建、查看、改名、删除会话。每个会话分别保存模式和消息；切换模式保留历史。 | [会话接口](../../backend/chat/api.py) · [侧栏](../../frontend/src/components/Sidebar.jsx) |
| 问答与报告追问 | 普通问答使用近期消息；眼科问答可在预算内固定最近一份报告，并随回复保存本轮检索和核验信息。完整历史与本轮送入模型的内容范围不同。 | [聊天服务](../../backend/chat/service.py) · [上下文选择](../../backend/chat/context.py) |
| 分析受理 | 接收 JPG、JPEG 或 PNG、病种列表、可选记录和会话标识。默认选青光眼，支持多选；无法解析的图片、过小或纯色图像会被拦截。 | [分析表单](../../frontend/src/components/ReportView.jsx) · [报告接口](../../backend/report/api.py) · [图像检查](../../backend/vision/utils/images.py) |
| 青光眼影像分析 | SwinV2 输出二分类概率，SegFormer 生成视盘环与视杯掩膜。分割用于计算面积等效杯盘比和生成叠加图；缺少视盘环时无法给出该比值。当前未评估分期。 | [青光眼分析](../../backend/vision/diseases/glaucoma/analyzer.py) · [视杯视盘测量](../../backend/vision/anatomy/optic_disc_cup.py) |
| 糖网与黄斑变性探索 | 糖尿病视网膜病变（DR）和年龄相关性黄斑变性（AMD）共享一次 FLAIR 图像编码，各自输出正负提示词的相似度差。依赖与权重可选，缺失时该请求明确报错。当前没有校准概率、分级或转诊阈值。 | [病种路由](../../backend/vision/analysis.py) · [视网膜模型](../../backend/vision/diseases/retinal.py) |
| 知识与证据检索 | 从本地语料召回带出处的片段。可用 BM25 关键词检索、向量检索，或用 RRF 融合排名；启用图检索时还可按概念与关系召回条款并附路径。报告和眼科问答共用该能力。 | [检索服务](../../backend/knowledge/service.py) · [图检索](../../backend/graphrag/retriever.py) |
| 专科分析与报告综合 | 将视觉输出和临床记录整理为病例事实。青光眼启用六个角色，选择 DR 或 AMD 时加入视网膜专科。专科并行处理，可查询本次证据包，Director 汇总为草稿。 | [角色选择](../../backend/report/service.py) · [病例上下文](../../backend/report/context.py) · [生成流程](../../backend/report/generation.py) |
| 引用核验与拒答 | 检查引用编号，并按配置核查资料是否支持陈述。报告可经历修订、复核、重新综合；核验开启且缺少证据或最终失败时，展示拒答原因。关闭模型核验时仍检查未知编号。核验范围限于外部知识引用。 | [核验器](../../backend/agents/verifier.py) · [校验结果展示](../../frontend/src/components/VerificationResult.jsx) |
| 结果归档与交付 | 正文接口保存报告、证据、核验结果、杯盘比及可用叠加图的标识。有会话标识时追加请求与回复并切换为眼科模式。历史 PDF 使用已保存结果，原始表单生成 PDF 的接口则会重新运行分析。 | [报告服务](../../backend/report/service.py) · [PDF 渲染](../../backend/report/pdf.py) · [存储](../../backend/utils/storage.py) |

## 阅读一份报告时，如何追溯其内容

- **病例记录**来自用户本次填写的文字。后续追问只使用上下文窗口选中的内容，较早的记录可能未随问题送入模型。
- **影像发现**来自所选病种的模型。青光眼的面积等效杯盘比按视杯面积占整个视盘面积的比例开平方计算；糖网和 AMD 返回的数值表示提示词匹配方向与差值。这几种数字应分别解释。[视觉输出说明](../../backend/vision/README.md)
- **外部知识**来自本轮召回的资料。可以沿引用查看来源和片段，部分证据还附图谱路径。核验通过表示系统接受了引用关系，影像质量与模型准确度仍需独立验证。[证据展示](../../frontend/src/components/EvidenceList.jsx)

React 页面、FastAPI 路由、SQLite、模型调用客户端与临时任务目录支撑上述流程。样例、算法讲解页面和研究文档用于演示或研发。后续工作及优先级见[项目改进建议](项目改进建议.md)。
