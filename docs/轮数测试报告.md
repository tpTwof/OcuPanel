## 2. 结论

- 满足四项判定的最小轮数上限是 **3**（可用档位：[3, 7]）。
- 更大轮数（[7]）也能通过，但没有带来额外收益，反而增加调用次数与等待时间。
- 不可用档位：[2, 4, 5, 6]。它们并非轮数不够，而是余留问题未能消解或链路故障——继续调大轮数不会解决这些原因。

## 3. 关键观察

1. **轮数没有单调收益。** 可用的是上限 3（后改用 7）：其余档位分别因余留问题无法消解而降级为病例摘要，或因核查链路故障扣留正文。轮数上限不是「越大越好」，结果在 LLM 随机性下波动。

2. **改写有效，且问题数整体在下降。** 日志中可见「3 处→1 处」「6 处→3 处→1 处」这类收敛；删除数恒为 0 是模型选择改写而非删除，本身不是缺陷。但轮数用尽时会强制整篇重生成（`verifier.py:293`），重生成后要全量重核查，成本与时延显著上升（上限 3 用了 829s、10 次调用）。

3. **余留问题里 0/8 是引文原文对不上。** 修正提示词、明确要求逐字复制后，这一项从上一轮的 6/10 降到本次的 0/8。实测模型在被明确要求时 12/12 条都能逐字抄对，所以这不是能力问题，而是指令没说清。

4. **单次调用最慢 164 秒。** 默认 `LLM_TIMEOUT=120` 会让核查稳定超时并扣留正文；现已改为 300 秒。首次实验在 120 秒下全部失败，本次才拿到真实结果。

5. **首轮判定质量波动大。** 各档首轮问题数为 1–4 处，同一输入、同一模型下并不稳定。这使轮数上限的效果带有运气成分：上限小的时候可能刚好不需要那么多轮，上限大的时候也可能被首轮质量拖住。

**初步评估**

模型分类器输出提示高概率倾向青光眼，但这是模型预测，不是临床诊断；模型未评估严重度，不能据此推断分期、进展或紧急程度。面积等效杯盘比（CDR）偏大，是对本次上传右眼眼底照的结构描述；CDR可用于描述影像所见，确诊仍需综合房角、视神经/视网膜神经纤维层（RNFL）和视野（VF）等评估[7][1]。结合记录，右眼眼压（IOP）偏高、房角开放、光学相干断层扫描（OCT）RNFL上方及下方变薄、视野鼻侧阶梯样缺损，需结合房角、视神经/RNFL和视野等进一步评估；但单次视野缺少可靠性指标和重复性，不能仅凭一次结果确定损害或进展[2][5][9]。左眼IOP偏高、房角开放，记录中视野未见明确缺损、RNFL尚在正常范围，且无左眼眼底照；不能由右眼照片推断左眼视盘，也不能据此排除早期损害。

**病例摘要**

62岁男性，因体检发现眼压偏高就诊；有高血压及母亲POAG家族史。双眼房角开放，右眼IOP 26 mmHg、左眼24 mmHg；右眼视野鼻侧阶梯样缺损，OCT RNFL上方及下方变薄；左眼视野无明确缺损、RNFL尚正常。本次仅提供右眼彩色眼底照。

**关键发现**

- 右眼：CDR偏大来自上传眼底照；IOP、RNFL及视野结果来自临床记录。模型倾向青光眼，但诊断确定性仍受视野可靠性、重复性及黄斑神经节细胞复合体（GCC）等资料未提供限制[1][2][10]。
- 左眼：判断来自临床记录，无左眼眼底照；现有记录未见明确结构/功能损害，但IOP偏高，且记录有POAG家族史，现有资料不足以排除早期损害。
- 未提供：中央角膜厚度（CCT）、Goldmann压平眼压、视野可靠性指标（固视丢失、假阳性/假阴性）及左眼视盘影像/立体评估；这些缺口限制双眼分别判断和诊断确定性[7][2]。

**下一步**

1. 复核已提供的右眼视野可靠性及可重复性；若存在可疑缺损，是否重复视野或结构检查由临床医生决定，以确认而非仅凭单次结果判定损害/进展[2][5][9]。
2. 对诊断评估缺口，按所引英国NICE诊断评估场景，CCT和Goldmann压平眼压属于诊断评估项目，是否补测由临床医生结合本例决定，并补充左眼视盘结构评估；这是为了完成综合评估，不代表已确诊[7]。
3. 若后续确诊并开始治疗，随访间隔需个体化；证据提示治疗初期或调整用药后4–6周复测IOP，稳定者每3–6个月复查IOP和视神经、每6–12个月复查视野与RNFL成像[3]。目标IOP应由专科医生结合基线IOP、损害程度和进展风险设定，不能以模型概率替代；目标IOP设定依据[4]。
4. 目前不依据单张照片或模型输出确定分期、进展或治疗方案。

本报告仅基于所提供资料；所引[7]为英国NICE诊断评估场景，[4][9]为美国AAO指南摘要，[1][2][3][5][10]为中国指南/摘要或诊断要点。模型概率高不等于确诊，资料未涵盖的内容不能补推。

本次分析显示：上传的右眼彩色眼底照被模型判为高概率青光眼，面积等效杯盘比（CDR）测量偏高；两者应分开理解：前者是分类模型输出，后者是影像衍生结构指标，均不构成临床诊断、分期或进展判断。右眼临床记录同时有非接触眼压偏高、房角开放、视野鼻侧阶梯样缺损及 OCT 视网膜神经纤维层（RNFL）上方和下方变薄，这些发现需按青光眼诊断标准综合评估 [1][2][5][12]；但单次视野缺少可靠性指标及重复性资料，且 CDR 可用于描述影像所见，确诊仍需结合立体视神经等检查综合评估 [7]。因此，右眼可表述为“原发性开角型青光眼（POAG）可能性需专科确认”，不能据此确诊、分期或判断进展。左眼记录眼压偏高、房角开放、视野未见明确缺损、OCT RNFL 尚在正常范围；无左眼眼底照，不能由右眼推断，目前不能诊断明确青光眼性损害，也不能排除早期或未检出损害。眼压升高与青光眼性损害应分别评估 [1]。

## 关键发现

- 右眼：模型分类为高概率青光眼；面积等效 CDR 偏高；已有右眼彩色眼底照（非立体）。临床记录眼压 26 mmHg、房角开放、视野 MD -4.21 dB、PSD 3.86 dB，RNFL 上方及下方变薄。
- 左眼：无上传眼底照；记录眼压 24 mmHg、房角开放、视野无明确缺损、RNFL 正常范围。
- 双眼眼压均为非接触测量；右眼视野为单次报告，可靠性指标未列明；右眼结构与功能异常需重复确认后才能判断损害或进展 [2][5][9]。
- 母亲确诊 POAG 为家族史记录。

## 缺失信息

资料中未提供或未列明：Goldmann 压平眼压、中央角膜厚度（CCT）、双眼散瞳立体视神经/视盘评估（右眼仅有彩色照，左眼无照片）、视野可靠性指标及重复视野、可用于分期或进展判断的纵向资料。模型未评估严重度。

## 下一步建议

1. 由眼科专科完成或确认 Goldmann 压平眼压与 CCT，并结合已提供的房角镜、视野、OCT 及右眼眼底照进行综合诊断评估；非接触眼压不能替代诊断流程中的压平测量 [7]。
2. 对右眼视野缺损，核对固视丢失率、假阳性率、假阴性率，并由专科决定是否重复视野；单次结果不能确定损害或进展 [2][5][9]。
3. 补充双眼散瞳立体视神经/视盘评估；随访中结合 RNFL 纵向变化，区分生理性变薄与青光眼性结构损害 [7][12]。
4. 若后续确诊并开始治疗，目标眼压需按基线眼压、严重程度、进展速度和预期寿命个体化设定，达标后仍需评估视神经和视野是否稳定 [4]；该治疗人群初期可在 4–6 周复测眼压 [3]，但是否治疗及具体间隔由专科决定。若纳入 OAG/高眼压症监测，应评估眼压、视神经、视野及依从性，频率个体化 [8]。
5. 左眼按记录继续监测眼压、视盘和视野，不以右眼结果替代左眼评估；具体复查间隔由临床决定 [8]。

## 局限性

本报告基于右眼单眼上传照片及有限临床记录；模型高概率和 CDR 偏高不等于诊断、严重度或紧急程度。缺少 CCT、压平眼压、立体视盘评估和重复视野，无法确认分期或进展；所引指南为摘要，适用性仍需结合地区及实际临床场景。
