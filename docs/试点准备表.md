## 逐眼标注表字段

一行对应同次检查、同眼、同任务；患者双眼与复诊始终同组。采集图像另以图像 ID 关联，多张与补拍不能覆盖旧记录。

| 字段组 | 必填内容 |
| --- | --- |
| 归属 | 机构、就诊编号、患者分组编号、年龄、采集时间及设备 |
| 影像 | 左 / 右眼、原图 ID、视野、可见区域、补拍序号、质量及原因 |
| 任务状态 | 未拍 / 未评估 / 不可判读 / 可判读；仅可判读时填写可疑或未见目标征象 |
| 阅片标签 | 阅片人、盲读轮次、可见所见及位置、影像是否值得转诊、分歧与裁决 |
| 临床参考 | 检查来源、日期、眼别、临床最终结论；未检查或未知单列 |
| 业务处置 | 重拍或人工安排、签发版本、转诊科室、责任人、时限、接单与到诊回执 |
| 方法对照 | 数据集版本、同组划分、旧版 / 候选固定版本、分数、锁定工作点、弃判、最终流程去向 |
